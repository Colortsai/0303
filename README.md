# 寶寶日誌 · 育兒紀錄網頁

單一 HTML 檔案的育兒紀錄工具，資料存在瀏覽器（localStorage），可部署到 GitHub Pages 免費使用。

## 功能
- 餵奶：親餵（背景計時，離開頁面不會停止）/ 瓶餵（母乳／配方奶＋奶量）
- 換尿布：大便／小便，含便秘、結晶尿、血尿等異常標記
- 溢奶／吐奶：一般／噴射性，噴射性可標記黃／綠／咖啡色／血絲
- 身長體重紀錄，對照簡化版 WHO 生長曲線（男/女）
- 台灣公費＋常見自費疫苗清單，可勾選並記錄接種日期
- 每日總結（餵奶次數/時間、尿布次數、溢吐奶次數、異常提醒）
- 一鍵同步每日總結到 Google Sheet（透過 Google Apps Script）
- 資料匯出／匯入 JSON 備份、深色模式

## 部署到 GitHub Pages
1. 建立一個新的 GitHub Repository（例如 `baby-log`）。
2. 把 `index.html` 上傳到 repo 根目錄（或 `docs/` 資料夾）。
3. 到 repo 的 Settings → Pages，Source 選擇你放檔案的分支/資料夾。
4. 儲存後幾分鐘內就能透過 `https://你的帳號.github.io/baby-log/` 使用。
5. 建議把網址加到手機主畫面（Safari／Chrome 的「加入主畫面」），使用起來就像 App。

## 串接 Google Sheet
1. 開一份 Google 試算表。
2. 「擴充功能」→「Apps Script」，貼上 `google-apps-script.gs` 的內容。
3. 部署為「網頁應用程式」，存取權限設為「任何人」，取得部署網址。
4. 在寶寶日誌網頁的「設定」→「Google Sheet 同步」貼上網址並儲存。
5. 到「總結」頁按「同步到 Google Sheet」，資料會寫入試算表的 Summary／Records 兩個分頁。

## 資料儲存說明
所有紀錄都存在瀏覽器的 localStorage，只存在這台裝置、這個瀏覽器裡。
- 換手機/電腦、或清除瀏覽器資料前，記得先在「設定」→「資料備份」匯出 JSON。
- 目前為單一寶寶單機版設計；若需多裝置同步，可定期匯出 JSON 手動搬移，或以 Google Sheet 同步紀錄作為雲端備份參考。

## 生長曲線的準確度
內建的生長曲線是 WHO 生長標準的簡化版本（僅 P3／P50／P97 三條線，12 個年齡點），用來大致參考寶寶落在哪個區間，
**不是**衛福部官方生長曲線圖的精確重製版，正式評估仍請以兒童健康手冊上的曲線與醫師判讀為準。

## 跟另一半共同編輯（家庭同步）
App 內建「家庭同步」功能，不需要登入帳號，只要兩人填入同一組設定即可即時同步。

### 如何取得 Firebase 設定
1. 到 https://console.firebase.google.com 用你的 Google 帳號登入，建立一個新專案（免費方案即可，不需要信用卡）。
2. 專案建立好後，左側選單「建構」→「Firestore Database」→「建立資料庫」，選擇「以測試模式啟動」（之後可以再調整安全規則）。
3. 回到專案總覽頁，點選網頁圖示（`</>`）新增一個網頁應用程式，取名隨意（例如「baby-log」）。
4. Firebase 會顯示一段 `firebaseConfig` 設定，裡面有 `apiKey`、`authDomain`、`projectId`、`storageBucket`、`messagingSenderId`、`appId` 六個欄位，把這些值分別複製貼到寶寶日誌 App 的「設定」→「家庭同步」對應欄位。
5. 自己想一組不容易被猜到的「家庭代碼」（例如 `dou-dou-family-8823`），填入「家庭代碼」欄位。
6. 按「儲存並連線」，狀態顯示「已同步」就完成了。
7. 把**同一組**家庭代碼和 Firebase 設定告訴另一半，讓對方在自己手機的 App 也填入同樣的內容並儲存，兩邊的紀錄就會即時同步。

### 安全性提醒
- 這個做法不需要登入帳號，家庭代碼本身就是存取門檻，請不要把代碼分享給不相關的人。
- Firestore 預設「測試模式」在一段時間後會自動鎖住，若要長期使用，建議之後到 Firestore 的「規則」頁面，改用以下規則讓資料庫維持開放（僅限有家庭代碼路徑的資料）：
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{familyId}/{document=**} {
      allow read, write: if true;
    }
  }
}
```
- 這組規則代表任何知道你家庭代碼的人都能讀寫該代碼底下的資料，安全性等同一組共享密碼，請選一組夠長、不容易被猜到的代碼。
- 若要停用家庭同步，回到「設定」頁按「停用家庭同步」即可，本機資料不會受影響。

## 疫苗清單的準確度
疫苗項目與建議時程整理自公費常規時程與常見自費項目，實際接種時程可能因政策調整、寶寶個別狀況而不同，
請以醫療院所及兒童健康手冊公告為準。
